# Security

If you find a security problem in PDFReader (for example, a PDF that crashes the app or makes it do
something it shouldn't), please email **techmaleek@gmail.com** instead of opening a public issue.
Include the macOS and PDFReader versions and, if possible, the file or steps that trigger it.
You'll get a reply as soon as possible, and credit in the changelog if you'd like.

PDFReader has no network features: it doesn't upload documents or signatures anywhere.
Saved signatures live in `~/Library/Application Support/PDFReader/Signatures`.
