# Changelog

## Unreleased
- **Info pane:** the ⓘ toolbar button (View ▸ Show Info, ⌥⌘I) opens a panel on the right with the
  PDF's details: title, author, creator, dates, page size and paper, file size, location, PDF version
  and security. It follows the page you're on and remembers whether it was open.

## 1.1
- **Sign PDFs:** save up to 5 signatures (draw with mouse/trackpad, or import a photo or scan),
  place them on any page, move, resize, delete, undo. Signatures are saved into the PDF.
- **Edit properties:** rename the file and edit title, author, subject, keywords and creator
  (File ▸ Properties…, ⌘I).
- **Saving:** File ▸ Save (⌘S), Save As… (⇧⌘S) and Revert to Saved. Undo/Redo in the Edit menu.
- **Dark mode:** View ▸ Appearance (System, Light, Dark) and dark pages for night reading
  (View ▸ Page Colors, moon toolbar button, ⇧⌘D).
- **Feedback:** Help ▸ Send Feedback…, Report an Issue, and a new About panel.

## 1.0
- First release: viewing, text selection, bookmarks and thumbnails, recent files, search,
  printing, password-protected PDFs, remembering your last page.
